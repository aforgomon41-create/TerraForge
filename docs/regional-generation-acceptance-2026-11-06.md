# 大陆与区域生成 · 第一轮验收

2026-11-06，本机完成并验证，尚未部署服务器。布局在用户直接查看预览并回复“ok”后接入，沿用浅色纸张界面与原悬浮面板。

## 实际变化

- 原选区可选“完整对象／自定范围”和“自动精度／指定格距”。完整对象使用自动识别的大陆、汇水区或地点范围。面板显示服务端核验后的真实采样格数和格距；指定精度不可行时阻止生成，不能暗改为自动精度。更换参数会作废并取消旧计划，提交前再次匹配查询身份。
- 父图采用真实三角面内的连续插值，按父图局部起伏限制新增细节，避免给平原统一叠加山地噪声。主河道提供初始谷底约束；侵蚀完成后不再全域拉回粗图。
- 计算选区外一圈最多24格的缓冲，再按完全重合的采样点裁出结果。父图边缘不能容纳缓冲时缩小或取消缓冲，不伪造图外地形。
- 显式保存图外上游来水、面积、月变化及出水水位，重开工程和逐月水系继续读取。部分覆盖的父格只登记一次图外源项。天然湖泊损耗按外部份额追踪，水头造成的额外蒸发供水单列，较高出口不能淹没可从较低出口排水的整张图。
- 新球面局部网格为v3：最大宽度由0.8倍星球半径扩大至2.4倍，面积按球面六角多边形计算；v2工程继续使用原有几何和面积。
- 独立区域／地点以连通主河道、支流、谷底和分水岭组织地貌，小尺度纹理只作为补充。山地、丘陵、平原、河谷和海岸保留不同的起伏方式。独立大陆的构造流程继续沿用现有实现。
- 冰雪以父图连续冰厚作为初始状态，在最终细网格上松弛500年，账本包含初始储量；缓冲区只继承冰雪背景并计算雨雪融水。根世界仍从零冰量演算10000年。没有把父图的冰雪元数据冒充细图求解结果。
- 修正球面局部图河流的米制坐标，以及该类地图风场／板块箭头的方向换算。渲染地图沿用现有自然彩绘和细分生态材质。

## 验证结果

核心25项、网格34项、模拟121项、服务端30项通过；前端53项、TypeScript检查、格式检查、生产构建通过。真实Vue组件的7种状态检查覆盖正常、指定精度、无对象、读取中、不可行、错误和生成锁定，不使用伪造组件。

生产Router在进程内执行，不启动额外HTTP服务。四类固定种子使用真实生成器：山地4200、平原4201、干旱河谷4202、河口4203。均通过年度收支、同种子复现，以及导出／导入后的高程、流量、湖泊损耗、年度／1月／7月水系和冰雪一致性检查。本组选区没有深度超过5m的人工大面积湖泊；这不意味着所有种子都不应有湖泊。

从既有种子42球形工程识别“大陆2”，完整范围宽10,520,761m，512×512采样，约20.55km计算格距。所有源大陆采样点均被覆盖。生成并导出约22～27秒，完整工程56,372,733字节，小于网页版64MiB导入上限；完整大陆也通过工程往返和逐月水系一致性检查。继续细化其内部“汇水区240”，范围约3097km、格距约6.05km、262144点，生成及诊断约9.5秒。时间来自本机开发构建，不能推断服务器相同耗时。

同一生产ES300着色器在本机AMD Radeon RX 7900 XT上渲染大陆和区域，GL_NO_ERROR，河流数量分别7528段和19938段。此项是渲染验证，不代替浏览器或手机操作验证。界面布局已由用户确认；本轮没有声称完成浏览器交互实测。

本机证据目录（生成物未入Git）：`artifacts/regional-acceptance-final`、`artifacts/regional-chain-final`、`artifacts/regional-paint-continent-final`、`artifacts/regional-paint-region-final`、`artifacts/refinement-panel-ssr`。可用 `cargo run -p tf-server --example regional_qa -- <输出目录>` 重跑四场景；再提供一个现有球形工程作为第二个参数可检查完整大陆及后续区域。

## 审查与边界

DSH同一只读会话 `5994a640-43c3-4bd3-b2b6-a9764b67081a` 三轮采用用户允许的 opendesign／deepseek-v4.1-flash／max，输出上限65536。主代理核实公开结论后修正部分格来水重复、月份口径、水头种子溢流上限及面板旧计划保护。关于ID为字符串的猜测与实际数值ID契约不符；“累计湖损被反复扣除”的推断由100→80→64的专项检查排除，未据此错误豁免外来水的蒸发损耗。审查没有覆盖完整物理模型，测试收支闭合也不代表模型已被地球观测标定。

本轮仍有明确限制：边缘混合格面积为细格面积积分近似；多次穿越选区的同一图外源水只在首次入域登记，尚未求解出域再入域的耦合反馈。父图未保存逐河段输沙量，外部泥沙标记为未知，只计算局部侵蚀产生的泥沙；侵蚀泥沙账本的范围是含缓冲区的计算域，元数据单列该范围，不能当作裁出地图的独立质量收支。局部气候沿用父图月背景和海拔温度调整，尚未实现独立的精细区域大气、洪泛、地下水或三角洲演化。自动概览遵守预算，大到跨过局部投影背面的对象会明确要求分区。
