# TerraForge 前端设计

## 已确认方向（2026-10-29）

用户要求：只保留全屏地图与悬浮 UI 的结构，其余界面重构；明确选择“浅色、纸张感地图工作台”。允许为当前项目调用生图制作素材。正式页面之前先审阅布局预览，未回复不视为通过。

用途：创建、观察、细化、探索与导出虚构星球的地理地图。桌面版作为正式产品；网页版提供临时体验，清楚说明数据保留规则。

## 视觉语言

- 地图占满窗口，以地图内容为视觉中心；面板可收起，不使用遮住地图的大型创建弹窗。
- 底色为温暖纸白 `#F5F2E9`，面板 `#FFFCF5`，分隔线 `#DCD8CC`，正文墨色 `#293831`。
- 操作主色为松绿 `#315F50`，辅助色为浅灰绿 `#DDE7DA`；进行中/提示用陶土橙 `#B7774C`，错误用暗红 `#AD4741`。
- 海洋灰蓝绿、陆地浅绿与赭黄、山地灰褐；默认纸张风格避免高对比荧光配色。
- 品牌、地图标题用系统衬线字体（Noto Serif SC / Songti SC / Georgia）；按钮、参数和正文用系统无衬线字体；数值用等宽字体。不依赖远程字体即可离线使用。
- 纸张感通过细微 CSS 纹理、细线、克制的阴影表达。按钮圆角 6～10px，面板圆角 12px；不沿用旧黑金毛玻璃。

## 布局预览（已审阅通过）

1. 顶部浮动工作条：品牌、世界名称/会话状态、球面/平面切换、导入导出、AI 入口。
2. 左侧工作面板：地图树与创建参数两个页签；世界、精度、种子、物理参数有清楚的单位与预算说明。
3. 右侧窄图层栏：地形、温度、降水、生态、高程、水文等实际可用图层；下面显示选区信息和“细化此处”操作。
4. 底部状态条：阶段进度、开始/取消、耗时与轻量状态。生成完成后收缩，避免长期占据视野。
5. 右侧 AI 抽屉按需展开，与图层面板互斥；先配置自定义供应商、模型和密钥保存方式，再开始对话。
6. 地图上的比例尺、经纬度与指北方向贴近画布边缘，不混入数据设置表单。

## 交互状态

创建、排队、运行、取消、失败、完成均采用后端真实状态；失败可重试，取消不显示完成。地图切换同步更新字段及 AI 上下文。生成中可查看实时阶段图，不因修改参数立即启动额外任务。

点击地图产生明确的选区标记；细化操作使用该位置及父图覆盖范围，不使用固定经纬度。树递归显示四层关系。切换图层同时更新图例及单位。

## 屏幕适配和可访问性

桌面宽屏采用左右悬浮工具区；小于 1100px 收缩面板宽度；小于 760px 左侧面板成为底部抽屉，同一时间只展开一个主要面板。工具入口支持触摸，按钮不依赖悬停出现。所有主要操作支持键盘、焦点状态与文本名称；尊重减少动画设置，地图缩放不禁止浏览器页面缩放。

## 素材与来源

预览地图采用项目内自制 SVG 示意，不代表实际模拟结果；图标为项目内 SVG。当前无新增外部网络素材或生图素材。后续若使用生成素材，在此记录用途、文件与生成方式；生成素材仅作装饰或示意，不能冒充生成中的真实地图。

## 世界投影实现

球形总图在顶部工程工具中切换球面与四种平面投影：等距圆柱、墨卡托、莫尔威德、Equal Earth。它们共享同一格编号与地理选区。投影的变形特点与适用范围见 2026-11-01 记录；比例尺表示视图中心处的距离。真正的平面世界以及大陆、区域与地点继续使用北向上的自身平面。


## 0.3 创建流程调整（2026-10-30，布局待审阅）

沿用已确认的浅色纸张工作台和全屏地图。用户新增明确需求：开局选择球形或平面世界；可独立创建大陆、区域和地点；增加实际有效的控制参数；连续地表与可调粗细的可选六角格网分离。

创建面板按“生成对象 → 基础/地貌/气候/星球/格网分组 → 预算摘要与生成”组织。世界支持球形或独立平面；其他三类默认独立平面，标明不依赖父图。生成后保留已有选区细化流程。地图格网仅改变可视化与选区尺度，不宣称提高模拟分辨率；单独显示模拟采样间距和显示格距。高级参数使用单位、默认值和效果解释，支持恢复默认。移动端使用同一分组的底部抽屉，生成按钮固定可达。

创建面板宽度拟从约 280 增至 380 像素，其余悬浮区域保持结构。布局预览 `docs/generation-preview.html`，创建表单尚未进入正式实现，需用户明确审阅。原有地图区域的连续表面、图层和显示格距修复按已批准的工作台布局推进。

## 0.3 尺度设置与随机种子修订（2026-10-30，布局继续待审阅）

用户要求种子可随机、不同尺度使用不同设置，默认世界陆地不应过碎。沿用已批准的浅色纸张风格，更新创建预览内容：默认自动随机，可关闭后填固定种子；实际种子保存进工程。世界提供大陆格局、海陆、构造与星球参数；大陆以单一主陆地、海岸和内陆山带为主；区域/地点提供局部地貌类型、范围、基准海拔、起伏强度、基准温度和年降水，隐藏全球板块/自转/恒星设置。区域默认 200×150 km、起伏 600 m；地点默认 10×7.5 km、起伏 80 m。创建预览已按反馈修订，用户尚未明确批准正式新表单。


### 2026-10-30 科学诊断入口
沿用已确认的浅色纸张、全屏地图和悬浮面板布局。在现有图层列表中增加用户要求的“板块与运动”：板块设色、汇聚/张裂/走滑边界和运动箭头。选区显示板块编号与实际速度（cm/年）；箭头统一长度，数值表示速度，避免把长度误当速度。旧工程缺少运动记录时明确说明，不补造运动数据。移动端仍在原“图层与选区”面板内操作。此改动不改变已确认布局；独立生成层级的大幅表单重排仍以预览审阅为准。

### 2026-10-31 平面世界边缘设置

用户明确要求控制平面世界的陆地能否被边缘截断。在现有“更多生成参数”内加入世界形态下拉和仅平面显示的“允许陆地被地图边缘截断”勾选项，沿用现有标签、选择框与勾选样式，不改变面板宽度或悬浮布局。默认勾选，兼容旧工程；关闭后保留海洋边缘，使大陆海岸留在图内。此项是地图取景约束，不改变板块运动边界，也不是首尾环绕。球形世界不显示边缘开关。完整分组创建表单仍待单独审阅。

### 2026-11-01 实时演化与投影

沿用已确认的纸张配色、字体、全屏地图与悬浮工作台，不重排页面。按用户要求，将顶部原有“球面／平面”选择框扩为“球面、等距圆柱、墨卡托、莫尔威德、Equal Earth”；真实平面世界和局部图继续使用自身平面，不套用全球投影。投影切换不重新生成，不改变格编号及地理选区；地图轮廓外不接受点选。墨卡托截去超过约 85.05° 的极区，等积投影用于比较面积；任何展开都会变形。

现有底部生成状态区域用构造时间、侵蚀步数或气候求解年／月替代静态阶段词。实时帧取自正在计算的状态，约每 0.5 秒采集一次；计算速度和网络决定实际间隔。预览采用较低精度，完成后切到全量字段。只保留最新待显示帧，断线重连恢复最新状态；切换投影保留当前演化画面。气候求解时间与构造的百万年时间分开标注，当前月累计降水不能冒充完成地图的年降水。未计算的气候／生态用地形预览表示，不宣称已得到最终生态。

投影方法参考 PROJ 官方文档与数学定义：<https://proj.org/en/stable/operations/projections/>。实现采用数学公式，具体对照与许可记录随实现保存；没有新增图片或生图素材。本次在已批准组件内增加选项与状态文字，不涉及仍待审阅的新建表单布局。

### 2026-11-01 自动地理对象

按用户纠正，在原地图树内展示自动识别的陆块、区域和显著自然地点；沿用已确认纸张风格和悬浮布局，不新增面板或改变主要区域。对象树可折叠，大列表逐步展开；对象点击定位并高亮真实成员范围，右侧原选区面板显示所属地理对象、类型和面积。普通地图点击也显示自动归属，地图投影切换后仍保持该对象。

原有手工裁图入口改称“提高此处精度／自定义精细图”，名称不再暗示用户裁出来的矩形就是大陆或自然区域。已保存精细图仍在原树中可打开，地理对象不受保存地图数量上限限制，也不在后台为每一个地点提前生成大图。识别加载、失败、旧工程补算与无陆地状态使用原组件的状态文本。地点先按山峰、山口、湖盆和河口处理，人文地点另需用户选择与生成依据。
