# 大陆、山脉与岛链修正记录

2026-10-31。沿用已确认的纸张地图工作台，只在现有“更多生成参数”中加入生成形状和边缘开关。本轮没有实现仍待审阅的大型创建表单。

## 已证实的成因与修正

- **圆弧山纹**：同一演化后的地壳，关闭火山仍有两条 C 形山带，关闭内部细节后消失。旧 `(1 - abs(fbm))^5` 会把噪声零等值线抬成闭合山带，现已移除。基础起伏使用有正负的盆地／高地场，褶皱纹理按保存的变形和厚壳方向组织。弧形山系本身并非错误，不把所有弧形构造一并删除。
- **陆块圆润**：初始圆头线段改为不规则地块和连接地体。匹配陆地面积时按比例扩大轮廓，不再用等宽的距离外扩填平海湾。地块主轴长度也已调整，避免少数随机种子在起始阶段便把相邻大陆连成大片。
- **漂移抹平海岸**：旧一阶搬运会持续混合陆壳和洋壳。改为局部梯度重建、半步预测和通量限制；搬走的岩石与留下的岩石严格对应，限制大陆相体积，保留 CFL、俯冲及开放边界收支。没有用锐化滤镜修改结果。
- **等距串珠岛链**：热点各自使用独立的间歇时钟，喷发间隔、体量和形状变化；历史火山仍随所在板块逐步移动。俯冲火山不再按网格扫描顺序布点，也移除了固定 220／700 km 去重间距。位置优先级由岩浆供给代理与汇聚速度决定，火山体尺度决定邻近排斥；已有中心可再次生长。
- **老火山再次生长**：出生年龄与喷发后的保留高度分别保存。已有山体继续衰减，新增加的部分按新增高度计入，避免刚喷出的部分也按几十百万年的出生年龄立即衰减。旧工程缺少新增字段时仍按原来的出生年龄计算。

以上属于可重复、可调节的构造形态模型，不是完整岩石圈力学、岩浆输送或真实世界历史重建。火山体的局部挠曲仍使用原有 Landlab 一维线载荷的径向形态近似，不宣称为二维弹性板解。

## 平面边缘开关

`allow_land_at_edge` 默认 `true`，旧工程缺少该字段也取 `true`，保持允许截断。关闭后在平面世界／大陆的图框周围保留随位置变化的海洋缓冲，重新匹配可容纳的陆地面积。球面及独立区域／地点忽略此选项。

这是创作上的地图构图约束；不会停止板块、环绕平面、改变地壳体积账或补回已经流出求解域的历史。极高陆地比例或极小网格不能同时保证海洋边框与精确陆地占比，此时海洋边框优先。边缘附近的海岸仍受有限画布影响。

## 验证方法

最终 Rust 核心检查 125 项通过（core 24、grid 31、server 15、sim 55）；前端 17 项测试、格式、类型检查与正式构建通过。命令为 `cargo test --locked -p tf-core -p tf-grid -p tf-sim -p tf-server --lib`，构建与模拟使用两个计算线程。

- 平直陆洋界面移动 20 Myr：旧算法把两侧海岸混合到一行共 12 个 100 km 格；新算法在多个内部横截面均不超过 6 格。仍有离散网格的混合宽度，不宣称完全无扩散。
- 平滑岩石场同时输运实际厚度、不同的参考厚度及变化的陆洋成分；网格间距和步长减半后误差降低，单独减半步长不导致误差增大。检查开放边界完整体积账。
- 保留球面刚体运动、单板块均匀场、示踪物运动、陆陆宽域增厚／洋壳俯冲、粗细转换、零时长、确定性与多种子大陆连通性检查。
- 单独检查均匀旧洋壳流过平面开放边界，不凭空产生山根；火山再次生长保留出生位置和年龄，同时确实增加当前地形幅度。
- 深海湾在地块扩大 1／2／3 倍时仍保留；边缘模式保存及缺省兼容、边缘全海洋、岩石台账不变均有回归检查。
- 最终完整样本包含球形种子 0／42、平面种子 42 的两种边缘模式。PNG 是生成器实际输出，非生图或浏览器截图。

本轮 DSH 原生会话使用用户允许的 `opendesign / deepseek-v4.1-flash / max`，实际输出上限 65536，承担只读成因调研和针对性复核。全部改动由主代理完成。其“流入量会额外叠加整格”的推断遗漏了邻格流出所替代的面积，未据此改写碰撞守恒公式；另补均匀开放洋壳测试核实。已采纳其火山新生高度衰减及输运验证覆盖方面的发现。

## 验证边界

数值预算闭合不等于地图外观或气候已完全拟真。山地高降雨、部分种子的冷区比例、沿岸沉积和冰川塑形仍待后续校准。本轮不以截断雨量、固定岛屿配额或强行分割大陆掩盖这些问题。

浏览器访问宿主不可用，原生浏览器又因无法可靠识别 URL 被 Computer Use 自动停止。未绕过工具限制；本轮只能核实代码、API、实际生成 PNG 和资源响应，不能声称完成手机触控与 WebGL 交互验收。桌面安装包尚未重打。
