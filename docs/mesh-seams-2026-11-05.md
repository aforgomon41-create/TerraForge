# 球面斜向接缝修正

用户截图中的细长斜带可在旧种子42工程的生产GPU绘制中重现。原因是球面 v2 使用的面内投影在边缘的极限与规范 slerp 棱点不一致；高分辨率下产生细长三角形，地形与光照沿这些三角形被拉伸。不是地图投影接缝，也不是正常河道。

## 修正

- 新球面几何 v3 使用对称正弦重心权重后归一化，在每条边严格退化为相同的 slerp。实时预览同步；Rust 与 TypeScript 的默认655362个坐标逐位相同。
- 不再把旧实现称为已验证的 Snyder 等面积投影。新插值并非精确等面积；求解器继续采用实际计算的单格面积。新网格六边形面积最大/最小约1.184，总面积保持球面面积。
- v2 坐标与编号通过 `build_legacy` 保留，工程、月气候与冰雪小网格分别按自己的几何版本读取。旧工程不静默换坐标，不自动重写用户数据；完整去除旧数据中的影响需要重新生成。
- 新几何会改变相同种子演化出的具体地图。回归中的“前三块陆地>70%”改为直接检查碎片占比：至少80%陆地在面积不低于总陆地1%的连通体中；保留最大陆块20%～85%、高程有限、非整片高原和相同输入确定性检查。最终大陆数量可以随裂解、合并改变。

## 已核实证据

- 旧真实655362格surface中最大三角形形状指标 `最长边² / 两倍面积` 为30.184，新网格为1.45309，接近正常三角形范围；没有调整地形着色器或模糊高度。
- 网格33项、服务端27项与前端51项测试已通过。模拟106项在完整运行中通过，修改后的多种子回归单独重跑通过（四种子各生成两次，513.77秒），合计107项；未声称一次运行全绿。
- `tf-grid --example verify` 已运行至最高频率768（5898242格），邻接与面积检查正常。
- 新默认世界从头生成并通过生产接口导出、导入核对，404.32秒；本机生产ES300着色器的球面放大、等距展开绘制通过，`GL_NO_ERROR`。
- 真实旧工程导入成功，surface逐字节相同（SHA256 `c85259bcaf7654f1a033936e9fe43b148a2611ef65cd790d4473ae6026a32979`）。

原生GPU图是实际着色器输出，不等同于手机或浏览器交互验收。图与指标保存在 `docs/references/mesh-seam-{before,after,world}.png` 和 `mesh-seam-metrics.json`。两版为相同种子重新演化的世界，地理形状会变化，不是同一地形逐像素对照。

## 只读复核

DSH 任务 `915f21ec-7773-4ab7-8de2-91eac788811b`，实际 opendesign / deepseek-v4.1-flash / max / 65536。首次范围过宽由主代理取消，随后同会话收敛审查并完成。主代理核实其边界连续性结论：三条边共用同一夹角依赖正二十面体各面等边，此实现只用于固定二十面体，不是任意球面三角形的通用插值。

对“派生粗网格升版”意见分别核实：已有月气候、冰雪 atlas 仍按其保存版本构网；新计算的粗网格和诊断网格是独立采样网，使用自身描述符，并按地理位置查询源字段，不要求与旧细网格嵌套。因此未将诊断点位置变化认定为字段错配。旧工程的显示网格／诊断箭头采样位置可能与旧版不同，原始场不变；旧工程surface实测逐字节相同。

陆块检查的变动与接缝修正分别记录：v3 seed0 的 top3=0.623322、最大陆块=0.429314，原 top3>0.70 检查确实失败；未把差异归为偶然随机，也未修改生成算法强制粘合大陆。新测试直接约束碎片面积和最大陆块，有限高程与确定性检查保留。该检查是产品回归指标，不是地球科学规律或“所有种子都只有四块大陆”的承诺。
