## 实际验收

- 本地核心 Rust 125 项、前端 17 项、格式与正式构建通过；未把桌面打包算入本轮验收。
- 新服务器二进制实际生成平面种子 42、189,440 格、关闭边缘截断；约 143 秒完成生成及后续检查。全部外边界高度为负，逐月资料可用，512 像素 PNG 有效，工程导出后重新导入仍保存平面形状与关闭截断设置。测试会话已清理。
- 经 Nginx HTTPS 再检查应用、3 个前端资源、参数保存、自动随机种子及会话清理；现有 `/map/` 仍返回 200。服务没有重启失败，实测内存峰值约 89 MiB；这不是所有种子、尺寸或导出负载的上限保证。
- 从本机通过普通外网 curl 访问应用与对照页均返回 200，3 个前端资源与正式构建逐字节一致。Cloudflare 会向 HTML 注入防护内容，因此不把外网页面整体字节一致作为证据。直接 Python 客户端仍被防护返回 403；没有关闭防护来通过检查。
- 浏览器工具因无法识别 URL 自动停止，未完成 WebGL／移动触控实机验收；没有以 API 或 PNG 检查替代这项结论。
