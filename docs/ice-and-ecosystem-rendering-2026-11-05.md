# 细网格冰雪与生态彩绘

用户对照图确认高程正常，规则六边形来自冰雪。v1 在2562点网格中心取地形／气候求冰，再插值至655362点；孤立厚冰的插值影响范围被不透明白色放大成六边形。此前网格接缝修正并未解决这一独立问题。

## 冰雪 v2

- 冰量、局地降雪／融雪／融冰与浅冰输运都在最终地图网格上求解，实际使用每点保存的年气候与月变化，不再用一个粗格中心代表周围低地。
- 活动集包含净积累格及冰流到达的格；只缓存这些格的月气候。保持10000年初始化、10年表面质量步，输运按供体体积CFL自适应子步走完真实时长，取消固定步长裁剪通量造成的堆积。每步检查取消；总输运步有资源上限，超出时不发布伪造的完成结果。
- 两个地图通道保存接地冰厚和浮冰厚；包括海底接地冰的真实体积。atlas v2 只保存来源、模型及预算，不复制大数组。年度和月份均直接读取本图的冰厚；子图按自己的地形重新求解，不继承父图的格点编号。
- 求解结束分别核对工作数组、实际输出通道体积、浮点取整及质量收支。降雪、表面融化、海洋基底融化、崩解、边界输出和储量都按细格实际面积计账。
- 积雪、海冰、湖冰和冻土继续使用细地形月气候。水文在冰雪之后更新液态输入、湖面及流量支持，再计算生态。固定的雪冰光学过渡是绘制参数，不冒充观测覆盖比例，也不改物理冰厚。

温暖裸地上的流入冰可以存在于消融带，厚冰表面也会因高度降低温度，因此不采用“裸地年均温>0℃必定无冰”或统一50m冰厚上限。更有效的检查是暖而无外来冰的区域不能自行成冰、远离冷峰不能继承粗格冰盖、实际输运体积可追踪。此前v1有1212个裸地年温>10℃且厚冰>=1m的格；v2同地形样本降至188个，不能把这188个一概删除。当前模型保留近似的浅冰、浮冰伸展、固定气候与温度递减率，尚不等同完整冰盖热力模型。

依据采用 [PISM 温度指数与表面质量模型](https://www.pism.io/docs/climate_forcing/surface.html) 的公开思路；本项目自己实现地图网格上的简化方程，没有接入完整PISM。体积守恒不能替代海气能量、海平面、冰崩动力及侵蚀全过程验证。原有冰川侵蚀是求冰前的独立床岩近似，未把床岩损失作为冰体积重复计账。

## 自然生态渲染

`data/ecosystems/paint.json` 提供大类回退及目前25个可识别细类的自然调色和23种结构样式；它不修改IUCN名录，也不虚构未实现的生态过程。针阔叶、季节疏林、云林、灌丛、草甸、泥炭湿地、岩地、热冷荒漠等都有明确映射，地方干湿和土壤估计再作克制调整。材质ID在顶点阶段解码，再插值结构权重，避免类别编号跨接缝混成另一种材质。

诊断RGB与自然RGBA分别占用现有14／15属性槽，保持WebGL2的16槽预算；预览、atlas重映射、原生GPU QA和浏览器捕获导出同步。无细分生态的旧工程保留旧材质回退。局部河流生境没有面积字段，因此只沿实际河道和湖岸显示，不将标签涂满整片地面。物理冰雪始终覆盖生态彩绘；有物理冰雪资料时，不用生态“冰原”标签强行增加白色。

## 验证进展

已完成：真实655362点球形工程、189440点平面工程从原项目重算冰雪／水文／生态，原始高程逐点不变。球形样本最高接地冰4602.37m、活动峰12141格、输运19157子步；独立平面活动峰542格、输运10580子步。实际输出冰体积与预算核对；月份、冰雪、水文、生态及工程导入导出经过生产Router复核。原生GPU的世界图和冰雪图已复现修正后的形状。
