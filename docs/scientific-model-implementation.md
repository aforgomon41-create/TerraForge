## 已落地

- **地壳随时间移动。** 采用球面 Euler 运动与守恒的有限体积搬运，保留地壳厚度、陆洋成分、年龄、压缩和走滑变形。默认演化 80 Myr；允许设置演化时间和小板块比例。初始大陆骨架是程序化初始条件，随后再运动，并非从地球历史重建。
- **几个大板块及更多小板块。** 初始分区采用不同权重和布点尺度。大陆和板块分别建模，大陆可以跨越板块，板块编号不会直接决定整片地形高度。
- **宽阔的大陆碰撞区。** 重叠陆壳增厚，侧向转移岩石体积，并用经验碰撞阻力减缓挤压。山地来自保存的厚壳与变形历史，不是在所有当前边界上统一抬高一条线。裂张通过减薄和新洋壳表现，走滑变形随地壳搬运并影响破碎地形。
- **不同成因的岛屿与海底地形。** 包括初始大陆地块及陆架、俯冲火山弧、固定地幔热点与随板块移动的旧火山。洋壳随年龄热沉降。火山弧使用沿弧平台、变化的岩浆供给代理和跨时期去重，避免每个时刻沿网格边界重复种植相同圆锥。以上仍是形态参数化，并未求解岩浆物理。
- **逐月气候。** 十二个等长模型月份使用真实日照几何、热容量、线性长波损失、对称热扩散与隐式求解。陆海热差风不再由“季风”开关一并关闭；水汽、云水和土壤水跨月延续，保存蒸发、径流、边界水量、储存变化及残差。
- **按水分需求区分生态。** 使用月温、月雨量、潜在蒸散和干季判断，冷旱草原不会仅因年雨量低就统一归为热荒漠。`biome_diversity` 对月气候路径也生效。
- **板块诊断图层。** 在现有面板内显示板块设色、汇聚／张裂／走滑边界和运动方向；点击可读实际 cm/年。箭头统一长度。边界使用有上限的诊断网格抽样，不代表每一条细网格边的精确轨迹；局部子图做相应投影。旧图缺运动资料时明确提示，不编造平移速度。

## 科学项目的实际复用

固定版本与完整 MIT 许可见 [third_party](../third_party/README.md)。

- climlab：日平均日照、海洋水柱热容量、A+B×T 长波公式及季节能量模型结构。原生隐式扩散求解器由本项目实现。
- Landlab：弹性挠曲长度和一维线载荷响应。用于火山负载的局部形态代理；缩放后不应解释为定量地壳挠曲预测。
- GPlates 的 Euler 旋转约定、Cortial 等人的构造历史思路是方法参考，未复制或嵌入其完整引擎。

实际在隔离 Python 环境执行了 climlab 0.9.2 和固定修订的 Landlab 模块，生成 28 组日照、热容量、挠曲长度和 3 组挠曲响应。Rust 测试与结果逐项比较；[重现脚本](../scripts/science_reference.py) 再运行后全部数值一致。Python 和 Fortran 均不是正式程序运行依赖；未使用的 Fortran 大气模块没有被算作已验证能力。

## 数值与保存

- 构造搬运每步根据当前速度重新约束 CFL，即保证每步不会搬走过多物质；发布构建同样检查。最多 4096 步，小范围或超预算平面构造参数提前拒绝；区域和地点使用各自的局部模型。0 Myr 不产生运动或新火山。
- 记录初始、新生、俯冲、开放边界输入／输出及最终地壳体积。平面外部输入使用明确的旧洋壳背景，不把外部流入当作洋中脊新生地壳。球面粗细网格转换分别校正陆壳和洋壳积分；平面输出裁切自带上下游缓冲的求解域，不能拿两种范围的总体积直接比较。
- 能量预算的温度基准是**海平面参考层**。地形表面温度通过统一高程递减率诊断；不能把参考层残差小误说成完整地形表面的能量闭合。保存温度基准、迭代年数及季节周期是否收敛。
- 月资料以独立网格压缩保存，编码与解码共用 32768 点上限；原始解压资料不超过 16 MiB，约束 Zstd 窗口和数组维度。子图追溯根图资料，不重复保存一份全球月场。
- 新增通道保存压缩变形、造山年龄、年潜在蒸散、干湿度。新增 `GET /maps/{id}/climate?cell=…` 和 `/tectonics`；沿用地图会话权限，并限制重型几何请求并发。
- 工程格式为 `tf-0.4`，继续读取 0.2／0.3。旧工程没有月资料时返回“不可用”；旧父图细化用明确的年均温近似计算 PET，不保存误导性的全零值。
- `precipitation_scale` 现在调整蒸发与水循环供给强度，不再对结果进行预算外线性放大。独立区域／地点的指定年雨量仍属于外部约束，其缩放系数单独记录，不能拿缩放后的降雨量解释原始输运账本。

## 验证与证据

- 仓库 CI 对应的 `cargo fmt --all --check`、`cargo test --locked -p tf-core -p tf-grid -p tf-sim -p tf-server` 通过：116 项 Rust 测试。前端格式检查、17 项测试及正式构建通过。
- 构造验证覆盖：刚体旋转、示踪物随板块移动、单板块不凭空造山、零时长、开放平面收支、球面粗细体积转换、大小板块分布，以及大陆宽域增厚与洋壳俯冲的区别。
- API 实测包含 655362 点世界、三级细化、逐月资料继承、工程往返、PNG、取消和跨会话拒绝访问。记录：`artifacts/science-v04-final-acceptance/report.json`。世界在本机两个 Rayon 线程下约一分钟；同时运行其他验证时更慢，不是性能保证。
- 降级的 0.3 年均资料兼容夹具导入后，月资料明确不可用，细化后的 PET 有效。记录：`artifacts/science-v04-legacy-report.json`。这是模式兼容验证，不是假称拿到了历史观测数据。
- 固定种子 42 和 0 均有 6 块超过 10 万平方公里的连通陆地；最大连通块分别约占陆地的 66% 与 34%。两者陆地海拔 99 分位约为 4.5 km 与 3.6 km，未再出现首版碰撞堆出 45 km 高原的问题。这些是特定种子的结果，不是对每个世界强制配额。
- 浏览器访问宿主不可用；原生 Edge 检查又因无法可靠识别当前 URL 被工具自动停止。未绕过限制，未声称完成 WebGL／移动端的实际视觉与触控验收。生成器 PNG 已逐张查看。

## 仍然存在的限制

此版本是面向创作的快速模型，不是完整地幔、岩石圈力平衡或三维大气／海洋环流求解器。碰撞阻力、下壳扩散、岩浆供给与寿命仍需校准；一阶输运会扩散细节。没有真实洋流、完整造礁、冰川与沿海沉积演化。PET 为经验 Thornthwaite 方法，不能当作严格潜热能量收支。

雨影随加密趋于收敛，但季节和热差风模型下仍存在接近 20% 的分辨率差异；目前只适合判断大尺度干湿关系。平面开放边界及持续地形抬升雨仍可能使山地年雨量偏高。种子 0／42 有很多高纬、高海拔陆地，冰盖与苔原合计超过一半；没有强行降低冷区或荒漠比例来使结果好看，仍需更广泛气候校准。

新创建面板的世界／大陆／区域／地点选择与成组参数仍等待 [布局预览](https://aforgomon.win/terraforge-previews/generation-v04.html) 的明确审阅。此门槛来自用户提供的 AGENTS.md“只有用户明确审阅通过后，才能继续正式制作前端”；原工作台批准未被当作新表单批准。
