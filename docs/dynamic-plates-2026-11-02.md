# 动态板块与内陆地形修正

底层演化与基础纸张渲染已实现，并通过正式优化版的本地完整验收。用户随后要求先比较自然彩绘、奇幻纸本、写实卫星三种画面样稿，待选择后才落实新的正式风格。服务器SSH持续握手超时，尚未完成上线，不能把本地通过理解为线上已经更新。下列中间构建与最终构建结果分别标明。此前报告中的“固定板块数组、每200百万年重撒”已经由本次实现替换，不能再当作当前代码行为。

## 已实现

- 历史身份编号只增加、不复用；计算数组使用另外的内部下标。记录出生、父板块、吸收关系、面积、最大面积、结束时间和原因。内部槽位回收前转移地质区与火山的归属，不清零旧岩石年龄。
- 地表采样点持续按刚体运动移动，保留小步累计位移。球面用欧拉旋转，平面用平移与旋转；平面改变旋转中心时同步转换平移速度，保持实际速度连续。
- 海洋采样点在实际接近的汇聚接触处被消耗；双侧浮力较高的大陆材料不会按同样规则删除。扩张间隙可以形成新的洋壳采样点；这不必产生新板块身份。
- 弱材料累积拉张损伤，足够贯通的弱带通过加权图割分出独立区域；持续分离的较大碎片也可独立。小板块与单一邻板的边界持续低相对速度时，可以被吸收。没有固定寿命、按时随机删板或定期重撒全世界。
- 小于当前分辨率、初始未解析、离开有限窗口、实际俯冲消亡分别记录。网格加密保留失去格子多数票的小板块采样点；不能把分辨率切换误写成球面板块“离境”。
- 板块诊断接口、保存和导入包含历史身份；局部细化地图读取根图身份表，避免每张子图复制整份历史。原板块面板可查看数量、新生／终止数量、选中身份、开始时间、当前／历史最大面积。导入校验编号、关联、事件顺序、时间和面积。

当前容量为48个计算槽位。已结束及初始未解析的槽位可在转移旧引用后回收；历史UID仍保留。有限窗口外仍存在的板块不被伪称为物理死亡。细小分裂超出容量时记录限制并在界面说明。

## 高原与火山根因修正

1. 对基线提交`d60e551`的40962格、种子42、4600百万年探针，侵蚀前最高点约17822米。其中火山贡献15745米、地壳根浮力约101米、基底约979米；海平面校准又整体抬高约924米。此前“27.5公里”属于另一中间构建，不混为同一数据。
2. 停滞热点现在持续建设同一火山复合体，保留原位置和年龄，以幅度与半径表示积累。相邻火山地貌使用共同表面包络，不把每次完整山体高度直接相加。仍属于程序化火山几何近似，尚非守恒的三维岩浆模式。
3. 搬运后的基底本身已有海陆过渡；不再把它与另一个深海底完整混合而重复淹没海岸，再靠海平面整体抬大陆补偿。海洋部分保留年龄相关热沉降。
4. 碰撞不再把整片盆地／旧地质区重标为年轻山地。只在实际接触附近留下随地块搬运、逐渐衰减的宽抬升区；盆地类型和原有年龄保留，最近变形年龄单独记录。远处仍可保持低地。古老材料的稳定程度也传入近期输运。

## 模型边界与科学依据

这是有动态身份和物质输运的程序化运动模型，没有求解完整地幔流动、热机械破裂或真实地球重建。古老时段使用粗采样点与移动地质区；最近最多120百万年另有有限体积地壳量账本。不能把近期守恒误差推广到整个46亿年的岩石预算。移动采样点计数也不等于岩石体积。

驱动速度场平滑变化，各板块拟合有上限的刚体运动。损伤、愈合与分裂阈值是生成器近似，未按具体地球岩石实验校准。历史／拓扑更新间隔不超过10百万年，运动内部继续细分；用户设置更短历史间隔时采用更短间隔。非线性分裂阈值附近，改变积分步长可以改变事件时间与后续分支，不能保证事件逐项完全一致。

- [GPlates拓扑与变形说明](https://www.gplates.org/docs/pygplates/pygplates_primer)：刚体、变形网络、随时间变化的拓扑与俯冲地表点退出，是实现参考；本项目没有运行完整GPlates重建。
- [Bercovici与Ricard，2014](https://www.nature.com/articles/nature13072)：损伤、弱带继承和微板块形成支持弱带累积变形的方向，不能直接提供本项目的经验阈值。
- [太平洋板块诞生研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5919776/)与[法拉隆残余碎片研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3619369/)：板块身份会新生、分裂、被消耗或并入其他板块；新身份可以包含很老的岩石。
- [克拉通稳定性研究](https://www.nature.com/articles/s41586-021-03600-5)：稳定的大陆材料与独立运动的板块不是同一概念。

风场／洋流沿用已实现的月尺度诊断与保守热通量。新增记录每月洋流整体缩放系数，以及最终风与滞后洋流强迫风的RMS差。界面说明一次滞后反馈和缩放；线性求解残差对应缩放前方程，不能冒充联合海气收敛或实测强度校准。

### 实时预览性能复核

默认球面655362格、4600百万年的开发版验收超过900秒；最初正式优化版也在900秒时尚处侵蚀阶段，没有当作通过或切换上线。进一步修正：

- 大陆材料之间不发生洋壳俯冲，使用顺序相同的洋壳候选桶跳过必然淘汰的配对。
- 同一小步内采样点位置不变，空间定位只做一次，碰撞与领域填充复用同一个结果。
- 网页实时观察者提供6000格的视觉预算，球面构造预览使用5762格，从当前求解字段插值和实际移动地质区／火山记录读取。古老时段也沿用该预览网格。实际物理求解网格和最终655362格输出保持原值，预览字段不会写回求解器。
- 预览地貌只读取地质区和火山记录，避免每帧复制整个移动采样点云。正常绘制间隔仍约0.5秒，实际帧间隔以运行结果为准。

新增10242格输入检查，确认预算生效且预览值有限，开启预览与关闭预览的最终高程、地壳厚度、板块归属和完整演化历史逐项相同。失败验收也保存已收到的帧和最后任务状态，便于复核，没有通过延长时限掩盖此前失败。
