本轮在 `codex/generation-fields` 上继续 tf-0.4 内核工作。新建面板仍等待明确的布局审阅，未提前接入正式界面。

## 已修正：空气错误地翻越海底

`climate_transport.rs` 原来把负的海底高程直接累加进大气网格，随后用于气流抬升。海底山脉和海沟因此会产生虚假的地形雨；沿海格子的深海部分也会抵消陆地的平均高度。

现在在面积平均**之前**使用 `max(高程, 0)`：海上是海面，陆上是实际高度。没有细网格覆盖时的外部背景也使用相同规则。陆海比例仍由原始高程的正负计算。

新增测试保持海岸、陆地和参数一致，只把海底从统一 10 m 深改为有起伏的 500–6500 m 深。修正前，测试实际失败，年雨量最大差异为 **13342.679 mm**。修正后，年温、年雨、潜在蒸散、全部逐月资料及水量账一致。模型没有海底驱动的洋流，因此这些输入不应改变空气气候。

这是一项可证实的计算错误修正，没有据此把所有山地雨量问题标为解决。

## 完整 climlab 模型对照

此前只逐项对照日照、热容量等公式；本轮实际执行了完整的 [climlab EBM_seasonal](https://climlab.readthedocs.io/en/stable/api/climlab.model.ebm.html)，并对照原生球面温度求解器。

- 上游版本：climlab 0.9.2，180 个纬度带，积分 40 年。
- 受控条件：均匀海洋、零倾角、固定反照率 0.27、太阳常数 1361 W/m²、长波参数 A=170、B=2、扩散参数 D=0.55。
- 特意使用偏暖的测试条件，让所有位置都高于 0℃，排除冰反照率反馈。它不是正式世界的默认温度设置。
- 原生测试网格：频率 12，共 1442 点；各点按实际面积计算误差。

| 指标 | 实测 |
| --- | ---: |
| 温度均方根误差 | 0.2476℃ |
| 最大温度差 | 0.8570℃ |
| 平均偏差 | -0.1015℃ |
| 原生模型最低温 | 5.9774℃ |
| 二阶纬向温差的扩散衰减系数 | 3.2828，理论值 3.3 |

上游结果固定在 `third_party/climlab/ebm-reference.json`。新增 Rust 测试直接读取上游温度数组，要求均方根误差小于 0.5℃、最大差小于 1.2℃，并检查周期收敛及能量残差。Python 只用于重现对照，不成为产品运行依赖。

```powershell
cargo run --locked -p tf-sim --example climate_reference
artifacts/science-venv/Scripts/python scripts/science_ebm_reference.py
```

这个结果支持温度求解器在该受控条件下接近上游模型，不能验证真实地球、山地降雨或默认世界冰原比例。

## 真实样本与剩余问题

复算平面世界种子 42、189440 点。修正后陆地年雨量中位约 **1824 mm**，99 分位约 **14529 mm**；上一候选版分别约为 1026 和 13324 mm。海底不再提前消耗来流中的水汽，陆地可以接收到更多水；极端雨量没有因此降低。

该样本的边界净输入约为 8.945×10¹² m³，海洋蒸发约为 4.021×10¹³ m³；水量残差约 150 m³，相对总输入约 3×10⁻¹²。预算闭合证明水没有凭空增加，不能证明雨量空间分布已经真实。气候改变也会影响后续侵蚀，最终陆地高度因此略有变化。

球形世界种子 42 同样复算了 655362 点：陆地年雨量中位约 294 mm、99 分位约 4257 mm；冰盖加苔原仍占陆地约 55.9%。高纬、高海拔陆地的寒冷格局没有因为修正海底高度而消失。

剩余重点是固定月风、开放边界来流及简化凝结过程。当前模型使用单个云水库和经验下降蒸发，与 [Smith 与 Barstad（2004）](https://journals.ametsoc.org/doi/full/10.1175/1520-0469%282004%29061%3C1377%3AALTOOP%3E2.0.CO%3B2) 的完整线性地形雨模型有差距；后者区分云水转化与水凝物降落，并考虑地形尺度对气流抬升的影响。该论文是方法依据，没有声称其完整求解器已接入。

下一步应先用独立迎风／背风剖面核对湿度、云水转化与降落延迟，再评估不同天气风向的贡献；通过实际水量账和加密检查选模型，不能只压低一个雨量常数或硬截断极值。
