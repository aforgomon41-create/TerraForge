# 分层生态分类

用户于2026-11-04批准分层方案，并明确审阅通过 `ecosystem-layout-preview.html`／`.png` 的控件布局。正式界面按预览实现完整名录、自然地表自动识别、地方变体、局部生境和判断依据。

## 分类基础

采用 IUCN GET v2.1 第三级作为全球统一名录：25个群系大类、110个生态功能类型。它不是物种清单，也不是现实最底层的地区生物群落。

来源为 [IUCN团队公开配置](https://github.com/red-list-ecosystem/typology-map-data/tree/c245ee11f58528a9cfdcb44dc8fd75253f08ac15/data/config)，固定提交 `c245ee11f58528a9cfdcb44dc8fd75253f08ac15`，MIT许可随数据保存。分类背景见 [IUCN](https://iucn.org/resources/conservation-tool/iucn-global-ecosystem-typology)及[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9581774/)。本项目只提取正式代码、英文名称、层级关系；中文是项目译名，颜色为项目定义，没有复制照片、地图或完整描述。

`data/ecosystems/catalogue.json` 是前后端共用名录。它记录25种有当前环境诊断规则的细类，其余类型按需新增过程／地下空间／人类活动分类标注。110种进入名录不表示能自动生成110种；一张地图只会出现自身条件支持的类型。

## 数据含义

原 `Biome` 的0～13含义保留，供旧工程、水文回退、土壤和既有渲染兼容。新增字段独立保存：

| 字段 | 内容 |
| --- | --- |
| ecosystem_biome | 地面背景／海底的25类群系编号，0为未识别 |
| ecosystem_group | 该背景的细类，0为条件不足、细类待定 |
| ecosystem_habitat_biome | 同位置的局部生境，如河流、海岸带、海面水体 |
| ecosystem_habitat_group | 局部生境细类，条件不足也保留0 |
| ecosystem_variant | 项目环境描述：干湿、地形、土壤背景 |
| ecosystem_evidence | 使用的输入和识别依据；不是统计置信概率 |

细类编号采用 `大类ID×16＋子类序号`，最高407；使用16位整数，禁止转成8位整数。正式代码仍如T2.2、TF1.3。编号在此名录版本内冻结，读取需要核对版本、整数范围和父子关系。

例如森林中的冻融河流，可以同时记录森林背景和F1.3局部生境；深海海底与上方表层海水也分开。海冰作为海面生境和现有季节状态记录，不把海底永久改成陆地冰原。

本阶段每格只有一个局部生境槽：河流优先于海岸带，河口不会被普通海岸标签覆盖，邻海条件仍单独记录在依据位中。这不是完整的三维、多生境空间模型；更细的河口、海岸与地下叠加留到相应过程阶段。

地方环境最多有64种组合，名称如“湿润·缓坡·冲积土估计”。它们只是项目环境描述，不是额外的IUCN正式细类，也没有宣称已模拟该地全部物种。水域不使用“干旱森林”等陆地描述，底质未计算时明确待定。

## 当前自动诊断

分类放在最终气候、湖泊、冰雪、土壤之后，只读取环境字段，不修改高程、原群系、水系或降雨。

- 用真实月温度、月降水、月潜在蒸散，区分雨林、干旱林、温带落叶林、照叶林、冷温带雨林、针叶林、季节干旱灌丛、草地、冷荒漠、半荒漠等。缺月气候或温暖地区缺有效蒸散时，保留上层群系。
- 用冰厚／常年积雪状态识别陆冰；用寒暖季、海拔和邻域坡度／起伏区分部分寒冻和高山类型。
- 用实际湖深的连通水面和可溢流条件估计冲洗型淡水湖；封闭湖缺少盐度状态时保留F2，不擅自判盐湖或淡水湖。冻融湖还要有对应月温度条件。
- 用已有汇水区面积和实际液态支持流量共同识别河流位置，作为单独的F1生境；无液态供给的干谷不标为河流。局部冻融气候支持F1.3。没有逐月上游流量时，不把干旱区大河简单判为间歇河或凭空声称常流。
- 海岸带可以识别上层位置；沙／泥／岩底、盐度、潮汐、植被条件缺失时不硬判细类。红树林、盐沼、三角洲、海草床、珊瑚礁等保持相应名录与待补过程。
- 当前海底仅保留陆架／深海海底的大类，斜坡、平原、海山、海沟等细分留到第三阶段；不能仅按深度将大片海盆标成海沟。海洋上层只记录可支持的表层水体／海冰，不虚构全部垂直生态。
- 人工湿地、农田、城市、种植园、养殖等不会随机生成；地下生态保留名录，等待相应空间模拟。

温度、干湿与地形阈值是本项目环境近似，不是IUCN发布的自动分类决策树。IUCN类别还涉及生物性状和生态过程，当前未模拟的火、放牧、土壤化学、盐度等不能用随机噪声代替。阈值附近的类型仍可能随真实输入和采样尺度变化；图层颜色插值不改变类别记录。

## 保存、接口与导出

通道27～32共6项；工程删除和失败／取消清理覆盖到32号。共享名录只存一份，不逐地图复制。每张地图只存状态数组和简短模型统计。

新版工程／新节点使用tf-0.6；新服务端继续读取tf-0.2～0.4旧工程。旧服务端不能可靠解释新增字段，不能将新工程伪装成旧版本。旧工程缺生态细分类时继续显示原14类，并提示重新生成。

`GET /api/v1/ecosystem-catalogue` 仅含固定公开分类资料，不含用户地图；`GET /api/v1/maps/{id}/ecosystems` 复用地图归属检查，返回六列f32二进制资料。读取是有界、单项重型导出许可保护的操作。点选接口也返回可用的六项字段。

PNG导出支持 `ecosystem=biome|group|variant|legacy`，缺新状态时回退旧配色，冰雪仍覆盖在显示之上。默认导出保留原海深／高程与群系配色；生态图层的导出按钮使用当前所选分类层级。正式前端使用同一套状态与名录。
