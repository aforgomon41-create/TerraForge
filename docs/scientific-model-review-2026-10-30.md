# 板块、海岸与气候的资料核验及模型改进建议

2026-10-30；核查版本 `e50c9ee`。本文是资料核验与实施建议，不代表下述模型已经实现，也不是新的前端布局定稿。

结论：用户对“板块应有大小层次”“碰撞应引起区域性地壳增厚”“岛屿需要多种成因”“现有气候偏简化”的判断基本成立。需要修正两点：大陆不等于板块；带状山系不只来自洋陆俯冲。当前问题同时涉及大陆初始化、静态构造截面、缺少运动历史、海岸过程与气候参数化，不能仅靠调整板块数量解决。

## 1. 科学核验

### 板块大小、陆地与岛屿

现实板块大小相差很大，一个板块通常可同时包含大陆和海洋岩石圈；大陆岸线不是板块边界。[USGS：板块是什么](https://pubs.usgs.gov/gip/dynamic/tectonic.html)。大小板块的数目随划分精细程度变化：例如 Bird 的 PB2002 模型明确包含较大板块及更多小板块，总计 52 个；这个数目是该模型的划分，不是地球板块数量的唯一答案。[Bird, 2003](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2001GC000252)。

因此，生成器应分别描述“岩石如何一起运动”和“哪里是露出海面的大陆地壳”。小岛可以位于巨大板块内部，夏威夷就是板块经过相对固定热点所形成的火山链；其年龄、沉降与侵蚀也有沿链变化。[USGS：夏威夷群岛地质](https://www.usgs.gov/publications/geology-hawaiian-islands)。增加小板块不会自动补齐岛链机制。

### 碰撞造山与线状外观

陆陆碰撞会导致地壳缩短、增厚、褶皱、逆冲和侧向变形；喜马拉雅山系与青藏高原是相关的山系—高原组合。某些板块交界是宽阔的变形带，不能统一理解为一根几何细线。[USGS：板块运动与边界](https://pubs.usgs.gov/gip/dynamic/understanding.html)。

“只有洋陆碰撞才形成带状山脉”不成立：陆陆碰撞也能形成沿碰撞带延伸的山系；反过来，洋陆俯冲也不只形成狭窄山脊，中央安第斯还包含 Altiplano–Puna 高原及显著的大陆地壳增厚，演化与缩短、下地壳流动和深部岩石圈过程有关。[中央安第斯高原综述](https://www.usgs.gov/publications/tectonic-evolution-central-andean-plateau-and-implications-growth-plateaus)。

应修正的是“把地形强度主要写成距当前边界的固定截面”。山系具有宽度、内部断裂与盆地、沿走向变化、年龄与侵蚀历史；部分边界在海底，走滑也不必产生高山。地形自然化不等于简单把全部边界模糊或隐藏。

### 岛屿、群岛和曲折海岸

至少应区分以下成因，不能全部用海面上随机加点替代：

| 成因 | 应出现的关联结构 | 依据 |
| --- | --- | --- |
| 俯冲火山岛弧 | 上覆板块一侧的火山中心、海沟、分段的弧形群岛 | [USGS：洋洋汇聚](https://pubs.usgs.gov/gip/dynamic/understanding.html) |
| 热点火山链 | 与板块相对运动相符的轨迹、火山年龄、侵蚀沉降后形成海山 | [USGS：夏威夷群岛地质](https://www.usgs.gov/publications/geology-hawaiian-islands) |
| 大陆裂解与地块拼接 | 大陆地壳碎片、裂谷、海峡及古缝合带 | [USGS：裂谷与边界](https://pubs.usgs.gov/gip/dynamic/understanding.html)；[Maine 地质调查局：地块拼接](https://www3.maine.gov/dacf/mgs/explore/bedrock/facts/geol-hist.htm) |
| 海平面淹没、河谷和冰川海岸 | 枝状海湾、峡湾、沿岸残留高地与岛屿，形态继承已有谷地 | [NOAA：河口的地质类型](https://oceanservice.noaa.gov/education/tutorial_estuaries/est04_geology.html) |
| 沿岸沉积与沙洲 | 沿岸障壁岛、潟湖，受沉积物和波浪搬运约束 | [NOAA：河口的地质类型](https://oceanservice.noaa.gov/education/tutorial_estuaries/est04_geology.html) |
| 珊瑚生长与基底沉降 | 合适水温、浅水环境中的礁与环礁，不能遍布任意纬度 | [NOAA：珊瑚礁如何形成](https://oceanservice.noaa.gov/education/tutorial_corals/coral04_reefs.html) |

裂解、岛弧和热点适合先在世界尺度实现；狭窄沙洲、礁和小峡湾应按实际可分辨尺度在区域或地点层表现。表中“应出现”是对本项目拟议模型的要求，不是每一真实岛屿都具有全部典型特征。

### 气候与荒漠

海边也可能是荒漠，冷洋流、副热带下沉气流、风向和地形共同影响沿海气候；不能统一给所有海岸加湿。[USGS：荒漠类型](https://pubs.usgs.gov/gip/deserts/types/index.html)。

年雨量不足以表达全部干湿与植被差异：季节分配、温度、蒸散需求、土壤水分和生长季都重要。Köppen–Geiger 分类就使用逐月温度、降水及季节性，并区分荒漠和草原气候；它是气候分类，不能直接等同于生态群系模型。[Beck 等，2023](https://www.nature.com/articles/s41597-023-02549-6)。

现有守恒水汽输运可以保留为数值基础，但守恒本身不证明蒸发、风和降水的空间分布真实。地形雨有包含凝结物输送和背风蒸发的成熟简化理论可参考，而不能只按山坡即时耗尽水汽。[Smith 与 Barstad，2004](https://journals.ametsoc.org/doi/full/10.1175/1520-0469%282004%29061%3C1377%3AALTOOP%3E2.0.CO%3B2)。

## 4. 建议采用的架构

推荐“保留地质历史的简化演化 + 独立气候求解 + 局部细化”。这是针对本项目速度、交互和可控性的工程方案，不声称等同完整地球物理模拟。

### 4.1 地质状态与运动

分别保存板块归属和大陆地壳分布。初始板块使用不等面积的层次生长，局部微板块优先出现在裂谷、转换或复杂汇聚区域；大陆核心也应有大小分布，保留大陆碎片。参数分别控制主要板块、小板块、初始大陆地壳、演化时长和裂解倾向，不用一个数量同时控制全部。

用旋转轴和角速度推进球面板块；大陆地壳与其年龄、厚度、历史变形一起移动。沿相接区域处理裂开、消亡、碰撞和拼接，使用物质收支而不是只把地面抬高。大陆连通性是结果和用户偏好，不能把“前三大陆越接近全部陆地越好”当成通用质量标准。

已有图学研究给出了可交互的简化方案：移动球面板块，保存厚度、年龄与褶皱方向，模拟俯冲、碰撞、新生洋壳和裂解，再补细节。适合作为实现参考，但该研究也有侵蚀、控制与物理近似的局限。[Cortial 等，2019：Procedural Tectonic Planets](https://perso.liris.cnrs.fr/eric.galin/Articles/2019-planets.pdf)。

### 4.2 区域变形取代统一边界截面

陆陆碰撞把累积缩短分配到具有宽度的区域，更新地壳厚度、变形方向与强度，形成高原、前缘山带、内部盆地和多列山脉；宽度取决于碰撞时间、汇聚速度和岩石强度。用浮力平衡求大尺度隆起，再加入岩石层弯曲、区域流动及侵蚀的简化响应，避免把所有增厚直接做成无限尖峰。

洋陆俯冲分别处理海沟、前弧、火山弧、陆内变形与盆地；洋洋俯冲通过独立火山中心生成分段岛弧。走滑在局部挤压或拉张弯曲处形成山地或盆地，不能沿全部边界统一加高。褶皱方向来自区域压缩，不能用贯穿全球的固定周期条纹代替。

需要保存旧造山带。边界移动或消失后，原有山地仍受侵蚀和新构造改造，地形就不会永远“描出当前板块边界”。

### 4.3 岛屿与海岸采用过程分组

先实现俯冲岛弧、热点轨迹、大陆裂解碎片和大陆架地形。火山增长、年龄与沉降共同决定岛、岛链和水下海山；不把所有火山都强行抬到海面之上。

海岸从海平面与陆架、谷地相交的位置产生。局部逐步补沉积物输运、河口堆积、沿岸搬运，以及冰川谷地与海平面变化。允许有平直海岸，不要求每一段都锯齿化。

世界经济档平均采样间距约 28 km，许多小岛、珊瑚礁和窄峡湾本来无法可靠分辨。显示格距不等于求解精度；应通过沿岸自适应细化，或保存火山中心等解析地貌供子图求值，不用放大真实小岛或增加随机碎点冒充分辨率。

### 4.4 气候从能量和水共同约束

保留现有守恒输运，增加逐月太阳加热、海陆热容量、混合层海温及海冰；海盆内的热输运与风场共同决定冷暖海岸。先实现受气压梯度、旋转与阻力约束的简化环流，逐月计算水汽、凝结、蒸发、土壤水、降雨和径流，并检查多年的稳定性。

地形雨保留凝结与降落延迟、背风蒸发，补充分辨不足山地的影响；不把大山当成每次都耗尽水汽的墙。干旱先由降水与潜在蒸散之比衡量，再结合季节缺水、生长季和温度分类；气候分类与植被分类分开。

若需要更高可信度，可另设离线高精度气候档，参考 PlaSim/ExoPlaSim 这一类中等复杂度三维气候模型。它们具有较完整的动力与热力框架，也需要更长的平衡计算；不能承诺直接装入当前网页生成时限，需先做运行时间、许可、平台和输出验证。[Hamburg：PlaSim](https://www.mi.uni-hamburg.de/en/arbeitsgruppen/theoretische-meteorologie/modelle/plasim.html)；[ExoPlaSim 论文](https://arxiv.org/abs/2107.07685)。

### 4.5 专门的板块图层

按用户要求，建议新增独立的板块图层：板块颜色与编号、汇聚/离散/走滑边界、宽变形带、运动箭头和局部速度（cm/年），以及选中两侧板块后的相对汇聚/滑移速度。颜色、箭头和数值应来自实际板块状态，而非装饰。

球面同一板块各处线速度不同，箭头应根据旋转轴和当前位置求值；同时说明运动参考系。普通地形层不画政治边界式分界线，但保留有地质依据的山脉与海沟。独立局部图未模拟全球板块时应明确状态，不编造箭头。此项只是拟议交互内容，正式前端仍遵循用户要求的设计与布局审阅流程。

## 5. 实施顺序与验收

1. 先修正验收：同时检查陆块/岛屿面积分布、海岸尺度、板块面积层次、山系宽度和气候；移除只鼓励陆地聚拢的质量目标。保留连续场和显示格网解耦。
2. 建立不等大小板块、地壳输运与历史记录，落实区域增厚。先验证理想化陆陆碰撞、洋陆俯冲、洋洋俯冲、走滑和裂谷，不先用复杂世界掩盖机制问题。
3. 补岛弧、热点运动年龄链、大陆碎片和陆架；将板块诊断图层作为检查工具。
4. 在地形样本固定后改进逐月气候和生态；再进行少量地形—侵蚀—气候反馈，检查稳定性。
5. 通过大陆架、河流沉积和海平面补充海岸类型，并在足够分辨率下验证。

验收应包含：

- 地壳体积/物质的来源与去向、面积覆盖无空洞、增加迭代精度后的收敛；不能只测试“没有 NaN”。
- 同一地形不同采样密度下，山系宽度、总隆起和主要岛弧位置稳定；热点链年龄与相对运动一致。
- 相同海平面、同等分辨率下统计完整的陆块大小分布与海岸长度，不预设所有世界都必须像现代地球，也不把某个岛屿数量定为普适真值。
- 固定地形的海陆风、迎风/背风、季节迁移和暖冷洋面情景；同时检查能量、水量收支与空间分布。
- 地球型参数可用已观测温雨气候作校准，虚构大陆则验证机制与守恒；不能把视觉更绿或某个荒漠百分比当作科学结论。
- 维护旧工程读取与算法版本标记；旧工程复现应锁定版本或明确迁移，不把新模型生成结果冒充旧种子的同版结果。
