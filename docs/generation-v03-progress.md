## 已实现的改进

1. 大陆地壳是连续属性场，不再按整块板块统一抬高。挤压、陆地裂谷、洋中脊、俯冲弧沟和走滑采用不同形变截面。边界影响加权混合；地壳混合区的热沉降及增厚响应连续，修复 0.5 阈值处台阶。特征宽度使用米；采样不足时过滤，避免永远只宽五格。
2. 板内有盆地、旧山带与多尺度起伏。子图继承父图后只补父图无法分辨的细节，使用根图坐标和种子，边缘继续受父图约束。此模型仍是运动学近似，不进行真实板块物质输运或完整地质历史演算。
3. 独立大气网格按真实面积输送水汽和云水，跟踪蒸发、降雨、土壤储水与径流；土壤水跨季保留。加入迎风凝结、背风再蒸发与季节风场。细地图用平滑权重和有界局部拟合重建降雨，避免大气三角面纹理。雨量参与侵蚀反馈。
4. 球面与真正的有限平面域分开；平面距离、面积和板块运动使用平面坐标。API 可从世界、大陆、区域或地点开始，根图不需要父图。平面子图继承根坐标基准；子图 API 可传 `cell_size_m`，返回实际采样间距。宽高比例超出预算时明确拒绝。
5. 服务端输出共享三角顶点与索引；正式前端移除独立正六角小片拼球。显示格网单独生成共享边界，有限域补齐外边界；球面保留拓扑上必需的 12 个五边形。切换显示格距不重新生成地形；前端显示服务端回传的实际格距。
6. 已增加的 API 参数包括起始层级、球形/平面、范围和参考经纬度、大陆尺度、造山/裂谷/走滑强度、内陆起伏、风速、地形雨、水汽再循环及显示格距，保留原有星球/气候/侵蚀参数。新表单尚未接入，不能把这些列为用户已经能在正式网站调整的功能。
7. 旧图缺少坐标时允许进入工程并重新生成；修正取消后的预览恢复和生成中投影视图；几何读取有并发上限与有限重试。工程继续支持 0.2 导入，0.3 校验真实格距及平面父子基准。
8. 根据用户反馈，默认大陆从噪声阈值改为连贯的地壳骨架；噪声主要补海岸与内部细节。增加主要大陆目标数量和海岸复杂度。保留初始低地基面，只用地壳厚度变化计算额外隆起，避免大陆内部普遍成为高原。
9. 种子留空自动随机，实际值保存进工程；固定值含 0 仍可复现。世界、大陆、区域、地点有独立默认参数；区域/地点使用局部地貌与指定气候背景，跳过全球板块。新分尺度表单仍待审阅，API 已实现。

## 已完成的验证

- Rust 核心共 99 项：core 23、grid 31、sim 33、server 12；`cargo check --workspace --offline` 包括桌面工程通过。
- 前端 17 项测试、Prettier、Vue/TypeScript 检查及 Vite 正式构建通过。
- 数值回归包含：闭球水量账、开边界恒定斜向输运、雨影、实际大气网格 75→37.5→18.75 km 加密后的误差收敛、跨三角边降雨梯度、混合地壳连续性、有限格网无悬空边、球面闭合拓扑和显示格距不改变生成字段。
- 服务测试实际生成无父图的平面区域，再细化地点，验证坐标覆盖、共享表面二进制和工程往返。四种起始层级与两种形状的域选择通过检查。
- 独立网页模式 HTTP 验收通过：655,362 点世界、三层局部图、重复选区种子一致、5 帧 SSE、身份隔离、取消、完整工程往返及 PNG。工程 16,281,363 字节，PNG 1024×512；证据在 `artifacts/acceptance-v03-web/`。并行检查期间世界耗时约 19 秒，不作为独占机器性能基准。
- 两个实际规模检查图：球面 655,362 点；平面 196,608 点。图片由服务端导出，已人工查看；不是 WebGL 截图。原始字段统计及图片在忽略目录 `artifacts/generation-v03-release-candidate/` 和 `artifacts/generation-v03-plane-candidate/`。
- 本轮再次通过独立 HTTP 验收：世界 655,362 点、三层细化、重复选区稳定种子、5 帧 SSE、身份隔离、取消、完整工程及 PNG 往返。世界约 12.6 秒，陆地海拔中位数约 869 m；工程 16,401,174 字节。证据 `artifacts/acceptance-continental/`。
- 本轮独立区域 HTTP 检查：自动随机后保存真实种子，用同一种子与参数重新创建，226,816 点高程字段完全一致；没有全球板块，指定平均年雨量 1,200 mm，实际平均误差小于 0.01 mm。证据 `artifacts/acceptance-local-random/`。
- 种子 42 主要三块陆地占全部陆地的比例从 34.3% 提高到 98.3%；种子 1 为 97.3%。多种子回归检查连通性与陆地中位海拔，并检查采样密度变化不破坏宏观大陆。

## 仍需完成

用户后续反馈大陆过聚拢、边界过明显、群岛与海岸不足及气候偏干。资料与代码核验见上方科学模型审查。种子 42 保存工程中，沙漠陆地采样点比例从上一版 14.47% 升至当前 35.46%；当前模型仍没有板块和地壳物质的时间输运，不能把连通性提高当作全面质量改善。后续应联合验收地质、海岸与气候；本文原有“已实现”不代表达到科学拟真。

- 用户的新创建面板布局审阅，然后接入全部参数、范围预算和独立起始层级。用户提供的 AGENTS.md 要求“只有用户明确审阅通过后，才能继续正式制作前端”；旧工作台布局批准不等于新创建面板批准。
- 重新实测网页 WebGL、移动端触控和新桌面安装包。当前浏览器访问宿主不可用；原生 Edge 检查也被工具因无法可靠确认当前 URL 而中止，未继续界面操作，未声称完成视觉验收。
- 上一轮平面示例山地雨量偏高（陆地 99 分位约 13,202 mm/年），需在新大陆格局下继续校准。当前球面种子 42 陆地雨量中位数约 249、99 分位约 4,586 mm/年；种子 1 为 282 和 4,215。大陆轮廓仍有圆弧感、褶皱存在重复感，尚未完成多种子视觉和科学校准。
- 独立区域/地点以指定年均温与平均年降雨作为外部气候背景，降雨根据输运结果重分布并归一到指定均值，不是封闭星球预算。有父图的细化继承父图气候；缺少上游环境时不能声称等同从完整全球气候截取。
- 连续场通过离散采样求解，并非无限精度。低于采样尺度的断层和降雨不能由显示格网变细凭空恢复。
