## 已实现的改进

1. 大陆地壳是连续属性场，不再按整块板块统一抬高。挤压、陆地裂谷、洋中脊、俯冲弧沟和走滑采用不同形变截面。边界影响加权混合；地壳混合区的热沉降及增厚响应连续，修复 0.5 阈值处台阶。特征宽度使用米；采样不足时过滤，避免永远只宽五格。
2. 板内有盆地、旧山带与多尺度起伏。子图继承父图后只补父图无法分辨的细节，使用根图坐标和种子，边缘继续受父图约束。此模型仍是运动学近似，不进行真实板块物质输运或完整地质历史演算。
3. 独立大气网格按真实面积输送水汽和云水，跟踪蒸发、降雨、土壤储水与径流；土壤水跨季保留。加入迎风凝结、背风再蒸发与季节风场。细地图用平滑权重和有界局部拟合重建降雨，避免大气三角面纹理。雨量参与侵蚀反馈。
4. 球面与真正的有限平面域分开；平面距离、面积和板块运动使用平面坐标。API 可从世界、大陆、区域或地点开始，根图不需要父图。平面子图继承根坐标基准；子图 API 可传 `cell_size_m`，返回实际采样间距。宽高比例超出预算时明确拒绝。
5. 服务端输出共享三角顶点与索引；正式前端移除独立正六角小片拼球。显示格网单独生成共享边界，有限域补齐外边界；球面保留拓扑上必需的 12 个五边形。切换显示格距不重新生成地形；前端显示服务端回传的实际格距。
6. 已增加的 API 参数包括起始层级、球形/平面、范围和参考经纬度、大陆尺度、造山/裂谷/走滑强度、内陆起伏、风速、地形雨、水汽再循环及显示格距，保留原有星球/气候/侵蚀参数。新表单尚未接入，不能把这些列为用户已经能在正式网站调整的功能。
7. 旧图缺少坐标时允许进入工程并重新生成；修正取消后的预览恢复和生成中投影视图；几何读取有并发上限与有限重试。工程继续支持 0.2 导入，0.3 校验真实格距及平面父子基准。
