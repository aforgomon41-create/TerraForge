# 自动地理对象

用户纠正：大陆、区域和地点应由生成结果自动识别，不能把手选矩形裁图及数值精度档位直接当成这些对象。

## 模型

地图是保存地形和气候的采样载体。地理目录是对这些实际字段的识别结果，包含自己的边界成员、父子关系、面积和位置，不创建数以千计的高精地图。

- 连片陆地识别为陆块，按面积区分大陆、岛屿；有限地图上触及外边界的只能称为陆地片区，不能推断外部完整大陆。球形连通性使用真实球面邻接，不受展开接缝影响。
- 区域沿实际排水关系划分汇水区，主要河网拆出子流域，小流域按相邻地形的最低连接处合并。分界由地形与水文产生，不按矩形划格。
- 显著地点识别山峰、连接山峰的鞍部、湖盆和河口；按当前采样精度选择主要地物，记录筛选数量。湖盆来自填洼水深，不能直接声称是有常年蓄水的湖泊。有限地图的排水出界口不称为海洋河口。

峰和山口采用高度降序的连通合并树：两座山相接时的高度给出连接鞍部，并据峰顶到鞍部的高差筛选显著山峰，参考 [TopoToolbox 的山峰显著度说明](https://topotoolbox.wordpress.com/2021/06/28/calculating-mountain-prominence/)。对于未完整覆盖的陆块，最高峰只使用当前可见地形的高差，不推断地图外部；边界上的峰与山口不作为已确认地点。地区与地点使用现有字段，识别不回写或改变物理模拟。

自动识别与再次细化可分开进行。世界生成完成即保存地理目录；已有工程首次读取时补算并缓存。工程携带目录，但导入时根据实际字段重建，避免过期或伪造目录影响识别。旧的采样地图保持可打开，界面将它们标为精细图。

## 依据与边界

参考 [GRASS r.clump](https://grass.osgeo.org/grass-stable/manuals/r.clump.html) 的连通区域概念、[r.watershed](https://grass.osgeo.org/grass-stable/manuals/r.watershed.html) 的流域和最小制图单元，以及 [r.geomorphon](https://grass.osgeo.org/grass-stable/manuals/r.geomorphon.html) 对尺度与地形识别的说明。这里为项目的球面／六角邻接自行实现图算法，没有声称运行了 GRASS 或完整移植 geomorphon。

大陆的地理命名还涉及历史文化，连通陆地不等同于地球惯用的七大洲。本项目给虚构陆块使用面积和连通规则，不强行套地球名称。识别精度受已有高程和水文采样限制，不将一个世界格子内未经解析的地形冒充精细地点。

## 接口与验证

`GET /api/v1/maps/{id}/geography` 受原有工程所有权隔离保护。响应为小端二进制：4字节 JSON 长度、JSON 目录、三条各含 `cell_count` 个 u32 的陆块／区域／地点归属通道，零表示无归属。目录不创建额外地图节点。压缩缓存不经通用 metadata 接口下发；解压、尺寸与编号均有检查。

136项 Rust 测试及27项前端测试通过。解析案例覆盖球面展开接缝、分离岛屿、平坦地形、已知连接鞍部、取消、编码损坏、会话隔离和工程导入重建。`scripts/geography_smoke.py` 对真实 HTTP 生成结果检查陆海归属、父子关系、定位点、缓存、地图数量和工程往返；它不是浏览器画面验收。

本地默认球形世界种子42：655,362格，识别3块大陆、310座岛、558个汇水区，以及山峰／山口／河口／候选湖盆；缓存读取约0.12秒，导入后重新识别约1.27秒。数目依赖种子与已有地形。Computer Use 无法可靠识别当前浏览器网址，已停止界面自动操作，未声称完成肉眼验收。DSH 本轮调研超时，追问入口未进入执行，已取消；本次结论及实现由主代理核实。
