## 已完成验证

- 75 项 Rust 测试通过：core 23、grid 27、sim 16、server 9；格式检查通过。
- 12 项前端测试、Vue/TypeScript 检查和 Vite 正式构建通过。AI 使用模拟流，不使用用户密钥。
- 隔离 API：四层生成、重复选区一致、跨身份拒绝、排队及运行取消、删除清理全部通过。
- 完整工程往返：5 张地图约 16.0 MB，导入后地点高程逐项一致。PNG 为 1,024×512，约 471 KB。
- 经济档 seed=42：陆地 29.19%，陆地中位高程 379.41 米；本机两线程开发构建世界 8.07 秒，局部三层为 1.27 / 0.31 / 0.35 秒。该速度不代表所有设备。
- 桌面第一轮标准档峰值工作集约 778 MiB。最终 NSIS 包为 2,333,346 字节；重新启动后工程恢复正常。原生窗口结构已核对，窗口截图接口超时，因此视觉截图使用同一桌面包提供的内嵌网页完成，没有把浏览器截图当作原生窗口截图。
- 界面：世界球面/等距圆柱平面切换、平面点击选区、实际下钻、保存大陆图重开通过；390×844 窄屏的工具栏、工程抽屉与 AI 配置通过。12 项前端测试包含投影切换后格编号一致的回归。
- 部署：2026-10-30 更新至代码提交 `9b97c7c`。服务器直连及经过 Nginx HTTPS 的完整验收均通过；后者世界 10.04 秒，三层局部图 1.24 / 0.33 / 0.33 秒，SSE 5 帧。与同时运行的公开浏览器生成合计，服务内存峰值约 394 MiB（限制为 900 MiB）。
- 公开网址：真实浏览器已成功建立会话、生成并显示 655,362 格星球。普通命令行请求仍可能被 Cloudflare 以 1010 拒绝；没有为通过检查关闭边缘保护。浏览器实测结果与源站 HTTPS 检查分别记录，未混为所有客户端均可访问的保证。

## 验证边界

- 尚无干净新电脑安装、macOS/Linux 桌面或高并发压力验收。Windows 本机通过不能替代这些检查。
- 高精度整球未做端到端验收，所需内存高于标准档。
- 地理生成是简化模型，尚无多种子科学校准；局部细化的格距不代表新增同等精度的观测数据。
- 未实现中途断点续算、地形编辑与撤销、人文推演、完整地下及覆盖层，未把这些列为已完成。
- 真实 AI 供应商的跨域和协议兼容性需使用用户自填配置验证。默认不保存密钥，主动勾选后写入浏览器本地存储，同源脚本可读取。
- GitHub 远程未提供；GPT 共同作者邮箱尚未核实，未使用猜测署名，也未声称 Contributors 头像已生效。
