# 内陆高原与分区显示修订

用户指出现实大陆内陆并不普遍是数千米高原和苔原，并要求显示自动分区。

## 已确认的原因

修复前使用生产构造／地形路径，把演化时间设为零，种子42、40,962格球面诊断仍得到陆地高程中位数4,239米、89.7%陆地高于3,000米；稳定内陆平均高程4,251米。初始基底只有约300米、地壳没有增加厚度，因此这不是合理的碰撞高原，也不是显示颜色问题。

初始海岸线处大陆地壳比例约0.45。随后的地形阶段把它与数千米深的洋底混合，导致设定的海岸沉入深水；末尾为凑足目标陆比又统一降低海平面，把稳定内陆变成高原。修正将海岸与陆洋地壳过渡分开：陆地与近海大陆架使用大陆地壳，地壳向外海逐渐减薄。保留真实地壳增厚产生的隆起，不把整个高程场压低或改成固定分位曲线。

修正后的同一零演化案例：陆地高程中位数约352米、稳定内陆平均334米，未出现3,000米以上的伪高原。球形／平面、多种子回归同时验证：20公里局部地壳增厚仍产生约3,030米隆起，没有抹去合理造山。

主代理核实了DSH只读审计：海陆基准与海平面问题成立；其提出的“可能重复施加均衡隆起”没有出现在现行生产调用链中，未据此删除造山项。基准厚度代表参考柱，同步把它改成当前厚度会消除真实增厚，不能照搬此建议。

常规80百万年、655,362格球面复查还发现第二个原因：大陆碰撞阻力始终使用固定响应时间，增厚的地壳没有带来更强的抵抗，长期推动使内陆过度压缩。仅修正海岸基准时，非极地内陆中位高程仍为2,092米、年均温6.08℃，约44.6%采样格是苔原或冰地。因此没有把第一次发布当作最终完成。

第二次修订让大陆碰撞阻力随超过参考柱的地壳根厚度增长：响应因子为 `1-exp(-dt/12*(1+(root/5000)^2))`，时间单位百万年、厚度单位米。它减慢持续碰撞的法向速度，不删除岩石、不抹平高程，不给大洋俯冲统一刹车。5公里厚度尺度与12百万年响应时间是生成器的经验参数，不是实测常数；这是运动学近似，并非完整的地幔力平衡求解器。演化记录中的模型标记更新为 `muscl-conservative-surface+episodic-volcanism-v4-buoyant-collision`。

## 科学依据与边界

[Whitehead 与 Clift 的原始研究](https://www2.whoi.edu/staff/jwhitehead/wp-content/uploads/sites/123/2017/11/2009_Whitehead_ContinentElevation_JGR.pdf)讨论了大陆厚度、侵蚀、海平面与高程关系，以及普通大陆低地和特殊造山高原的区别。这里使用该物理判断检查生成器，没有运行或移植其完整地球演化模型。

[NOAA 的海底地形说明](https://www.noaa.gov/education/resource-collections/ocean-coasts/ocean-floor-features)将近岸浅水大陆架、陆坡与深海盆地区分开；[USGS 的大陆架研究](https://pubs.usgs.gov/bul/1067/report.pdf)也指出大陆架是被浅水覆盖的大陆延伸。模型中的海岸线与陆洋地壳过渡因此分别处理，不把每个海岸都当成大陆与大洋地壳的分界。这里仍是平滑过渡的简化，不是逐段拟合真实被动／活动大陆边缘。

苔原判定本身来自最暖月温度，不能只因是内陆或高海拔就认定为苔原；[英国气象局的气候分类说明](https://weather.metoffice.gov.uk/climate/climate-explained/climate-zones)给出最暖月0–10℃的苔原气候范围。现有气候计算会按高度降低近地面温度，伪高原会间接制造大面积冷地。修正先恢复地形基准，再让气候和生态按真实新高程重算，不规定苔原、森林、荒漠的面积配额。

[印度—欧亚碰撞的原始力学研究](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2001JB000208)将重力势能差纳入大陆变形的力平衡；[薄黏性片与三维模型比较研究](https://academic.oup.com/gji/article/187/1/10/559502)讨论了厚化与重力扩展的竞争。本次只借鉴“厚化会增加抗继续压缩的重力作用”这一方向，没有移植论文求解器，也不将上述经验因子当作论文公式。

局部碰撞、火山、侵蚀和气候仍是简化近似，不保证每个随机世界都等同地球。原工程字段保持自身结果；重新生成后使用新地形逻辑。

## 自动分区显示

在现有图层中新增“自动分区”，选择大陆与岛屿、汇水区域、自然地点。设色读取地理目录的真实归属编号；边界由实际地形三角形的相邻标签构成，并沿双网格中线绘制，不使用裁图矩形。地点只显示识别到的点位／湖盆采样范围。

球面展开继续复制原格编号与颜色，边界通过既有投影接缝处理。图例是类别说明，不把颜色当作连续高低。生成过程中仍显示实际地形，完成并识别后切入分区；等待和失败状态可见。超大边界集有明确线段预算和提示，颜色归属不删减。

## 验证

138项Rust检查、31项前端检查、正式构建及格式检查通过。新增测试覆盖零造山大陆架、多个种子、球形／平面、局部地壳增厚保留隆起，以及分区边界的两类／三类交汇、球面投影接缝、空地点范围和边界预算。碰撞试验验证厚根具有更强阻力、零时间不改运动、小时间步响应收敛、最大时间步不反向、大洋运动不被抑制，并检查地壳厚度未被改写。

本地真实HTTP生成经济档、655,362格球形世界，种子42、演化0百万年：完整地形—气候—生态链约44秒。陆地中位高程420米，全部陆地低于1,000米；纬度±50°、距海超过300公里的内陆有126,933格，其中位高程479米、平均气温17.7℃，仅22格为苔原，其余主要为草原、森林等，含少量荒漠和湿地。此控制案例验证了普通内陆不应自动变成高原冷地，不代表有真实造山的所有种子。

第二次修订后的真实HTTP常规球形世界，经济档、种子42、655,362格、80百万年：126.81秒完成，陆地中位高程1,153米、90分位1,694米，41.3%陆地低于1,000米，0.33%高于3,000米。纬度±50°、距海超过300公里的97,888个内陆采样格，中位高程1,313米、年均温13.72℃；64.3%为温带森林，苔原约1.49%、冰地约0.40%。这里是采样格比例，不能等同严格的面积加权全球统计，也不能以单种子证明所有参数拟真。

自动识别、保存导入后的归属一致性、会话隔离均通过。旧工程的分区可以直接显示，新的地形结果须重新生成。

第二次DSH只读审查未发现符号、时间步稳定性或直接修改岩石量的问题。主代理另查 `plates::find_boundaries`，确认 `normal_velocity` 是带符号速度，发散为负；因此无需为该疑问修改筛选逻辑。速度测试检查的是两板共同平移速度之和，不假设每个六角边界法线都沿x轴；测试已通过。补上零时间、小步长比值和1.5百万年上限测试后再次通过。该审查不是完整全球力学守恒证明。

浏览器连接宿主不可用，未将这些数据与数学检查记为WebGL画面或移动触控实机验收。

第一次修订的本地真实HTTP平面世界189,440格、种子42、80百万年：约66秒完成，陆地中位高程645米，62.5%陆地低于1,000米，约8.8%高于3,000米。第二次修订另做同参数完整复查，结果见发布记录。
